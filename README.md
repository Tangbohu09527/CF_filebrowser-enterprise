# FileBrowser Enterprise

## 中文

### 项目介绍

FileBrowser Enterprise 是基于 FileBrowser 开源项目的企业级二次开发版本。

### 定位

企业文件中心基础平台。

### 当前能力

- Browse / Preview / Download 三权权限模型
- Token 权限交集
- WebDAV 权限控制
- Public Share 权限增强
- Archive 安全增强
- 前端权限控制基础

### 版本

`v0.9-enterprise-base`

### 路线

#### v1.0 企业可运营

- 权限闭环
- 审计日志
- 回收站
- 用户组
- 企业部署

#### v1.1 协作治理

- 标签
- 元数据
- 文件治理

#### v1.2 自动化平台

- Task System
- Workflow
- OCR
- AI Gateway

#### v2.0 AI 原生文件中心

- RAG
- Knowledge Space
- Agent Workflow
