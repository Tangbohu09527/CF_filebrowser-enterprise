# FileBrowser 上游比较

## 默认边界

默认只分析已有本地引用。未经用户明确授权，不执行网络 fetch，也不执行 merge、rebase、cherry-pick、reset、push 或任何工作区清理。不得修改、恢复或覆盖本地补丁和用户未提交内容。

## 分析流程

1. 读取根目录 `AGENTS.md`，确认当前分支、远程名称、工作区状态和比较目标。
2. 使用已有 refs 确定 merge-base，分别查看提交列表、文件统计和关键 diff。
3. 按功能、修复、安全、依赖和生成文件分类上游变化。
4. 将上游变化映射到本地二开补丁，标记无冲突、语义冲突和行为重复。
5. 识别已被上游覆盖、可以删除的本地补丁，但不自动删除。
6. 根据依赖关系和风险给出同步顺序与每一步验证范围。

## 固定输出

- 上游新增功能。
- 上游安全修复。
- 与本地修改的冲突位置及原因。
- 可以删除的本地补丁及证据。
- 推荐同步顺序。
- 同步后的回归测试清单。

明确列出比较 refs、merge-base、数据是否可能过期，以及未执行 fetch 导致的限制。建议命令不等于授权，不得自动执行改变 Git 历史或远程状态的操作。
