# FileBrowser 安全审查

## 审查流程

1. 读取根目录 `AGENTS.md`、相关实现、调用入口和现有测试。
2. 建立攻击者身份、权限、输入路径、目标文件和预期拒绝行为。
3. 沿 HTTP、WebDAV、分享、编辑器和 Token 请求链追踪规范化与授权顺序。
4. 发现疑似问题时先添加或运行最小复现测试，确认问题真实存在。
5. 未经明确要求不要直接修复；需要修复时只做最小改动，禁止大范围重构。
6. 报告受影响入口、普通用户可利用性、Token/分享边界和建议回归范围。

## 检查清单

- 路径穿越和路径规范化次序。
- URL 编码、双重编码及特殊字符绕过。
- 符号链接逃逸和根目录外访问。
- 任意文件读取或下载越权。
- 未授权创建、截断和覆盖。
- 删除、复制和移动越权。
- WebDAV 权限绕过。
- 分享链接和分享上传绕过。
- Token 权限超过用户权限、权限撤销失效或范围扩大。
- 上传文件名、分隔符、保留名称和特殊字符。
- 压缩包解压路径穿越和符号链接条目。
- 日志、错误响应或调试输出中的密码、Token、Cookie 和敏感路径。

## 约束与输出

- 使用普通用户和最小权限身份验证问题，不能只测管理员。
- 不访问生产服务、数据库或正式存储。
- 不用管理员权限、关闭检查或削弱断言证明修复。
- 按严重性输出证据、文件位置、复现方式、影响和建议；没有复现证据时明确标记为待确认。
